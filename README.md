# アクセスマップ作成ツール（京都・仙台）

物件から主要エリアへの行き方（バス・電車・徒歩）をまとめた
アクセスマップ（1600×1000 の画像）をブラウザだけで作るツールです。

| エリア | 行き先 |
|---|---|
| 京都 | 京都河原町・四条烏丸・京都駅 |
| 仙台 | 一番町・勾当台公園・仙台駅 |
インストールもログインも要りません。`index.html` を開けば使えます。

## 使い方

1. `index.html` を開きます（公開URLは下の「公開のしかた」を参照）。
2. **① 物件**：画面上の大きなボタンでエリア（京都／仙台）を選びます。物件ページのURL（例 `https://atinn.jp/building/3840`）を入れて「読み込み」を押すと、物件名と住所が入ります。
   読み込めないときは物件名・住所を手で入れ、「位置を検索」を押します。プレビューの地図をクリックしても位置を置き直せます。
   物件が選んでいるエリアと別の都市にあるときは、エリアが自動で切り替わります。
3. **② 行き先**：物件の位置が決まると、自動で経路を調べます。
   1. バスで乗換なし（バス停までの徒歩＋路線に沿った距離から推定）
   2. ①がなければ電車（直通または乗換1回）
   3. どちらもなければ道路の経路距離から推定

   電車やバスより歩いた方が早い近い行き先（徒歩15分以内）は「徒歩」と表示します。
   路線データを取得できなかったときはその旨を表示し、30秒後に自動で調べ直します（2回まで）。

   時間は目安です。所要分やQRのURLは手で上書きできます。QRは、京都市バスの系統が見つかればその時刻表ページ、それ以外（仙台を含む）は Google マップの経路検索を開きます。
4. **③ 見出し・表示**：タイトル・最寄りバス停・地図の範囲などを必要なら直します。
5. 「PNG保存」「高解像度PNG」「SVG保存」で保存します。

入力内容はブラウザに保存されます（物件ごとの内容はタブごと、見出しなどの設定はこのブラウザの全タブで共有）。
公開URL（ドメイン）が変わると、以前の保存内容は引き継がれません。

## 使っている外部サービス

サーバー側の処理はなく、ブラウザから次のサービスを直接呼びます。社内ネットワークで使う場合は、これらへの接続が許可されている必要があります。

| 用途 | サービス |
|---|---|
| 住所 → 位置 | 国土地理院 住所検索（msearch.gsi.go.jp） |
| バス・電車の路線データ | OpenStreetMap Overpass API（overpass-api.de ほか予備2か所） |
| 道路の経路距離 | OSRM（router.project-osrm.org） |
| 物件ページの読み込み | 直接取得できないときは api.allorigins.win / corsproxy.io を経由 |

OSM の路線データは有志の登録なので、抜けや古い情報があることがあります。公開前に路線を確認してください。

地図・イラストはこのツールが京都・仙台の通りや川・線路の位置から描いた図で、外部の地図画像や素材は使っていません。
QRコードの生成には qrcode-generator（MIT License, Copyright (c) 2009 Kazuhiko Arase）を `index.html` に同梱しています。

## 公開のしかた（GitHub Pages）

1. GitHub のリポジトリで **Settings → Pages** を開きます。
2. 「Build and deployment」の Source を **Deploy from a branch** にし、`main` と `/ (root)` を選んで保存します。
3. 数分後に `https://<組織名またはユーザー名>.github.io/<リポジトリ名>/` で開けます。

HTML 1ファイルだけなので、社内サーバーなどに `index.html` を置くだけでも動きます。ブラウザは Chrome／Edge の最新版を想定しています。
